# My Codédex python exercices

This repo contains my solution to the exercices of the python course and code challenges on Codédex.

## pattern.py

Creates a visual pattern using loops and spacing.

## area_calculator.py

Calculates area based on user input and basic geometry formulas.

## fizz_buzz.py

Prints numbers with Fizz, Buzz, and FizzBuzz logic.

## bmi.py

Computes body mass index from height and weight values.

## coin_flip.py

Simulates a coin flip and reports heads or tails.

## credit_card.py

Checks credit card validity using a validation algorithm.

## currency.py

Converts an amount between different currencies.

## debugging.py

Exercises bug fixing and code troubleshooting skills.

## even_odd.py

Determines whether a number is even or odd.

## food_ratings.py

Ranks food items based on user-provided ratings.

## grades.py

Calculates grades and letter scores from test results.

## hypotenuse.py

Finds the hypotenuse of a right triangle using the Pythagorean theorem.

## initials.py

Extracts initials from a full name input.

## letter.py

Generates or evaluates a letter-based challenge.

## magic8.py

Mimics a Magic 8 Ball with random responses.

## moores_law.py

Models the growth of computing power over time.

## pet_age.py

Converts a pet's age into a human-equivalent age.

## ph_levels.py

Classifies pH values into acidic, neutral, or basic ranges.

## quadratic_formula.py

Solves quadratic equations using the quadratic formula.

## script.py

A general-purpose script used for small coding exercises.

## sorting_hat.py

Sorts a user into a Hogwarts house based on choices.

## temperature.py

Converts temperatures between Fahrenheit and Celsius.

## the_cyclone.py

Simulates a themed challenge based on a cyclone concept.

## year_of_the_snake.py

Calculates or identifies the year of the snake from a cycle.
